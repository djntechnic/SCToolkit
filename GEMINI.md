# SCToolkit Gemini Project Index

This project keeps **one** authoritative architecture index: [`CLAUDE.md`](CLAUDE.md). Read it there — core principals, common commands, architecture, PR workflow, and agent guidelines.

SCToolkit deliberately no longer maintains a duplicate copy of that index here. A mirrored second copy drifts silently, and a drifted agent index is worse than no second index at all. All rules, audit gates, and standards defined in `CLAUDE.md` are 100% authoritative for Gemini.
